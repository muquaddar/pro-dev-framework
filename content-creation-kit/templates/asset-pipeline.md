## File Naming Convention

All delivered files must follow this naming pattern to avoid confusion:

```
[project-id]-[category]-[name]-[size].[ext]

Examples:
  myapp-icon-1024.png
  myapp-char-hero-happy-2x.png
  myapp-bg-home-1x.png
  myapp-narr-intro.mp3
  myapp-sfx-success.mp3
  myapp-screenshot-01-iphone69.png
```

## Folder Structure (Delivery)

```
[project-id]-assets/
│
├── icons/              ← IC-## files
├── characters/         ← CH-## files (organized by character)
├── backgrounds/        ← BG-## files
├── ui-illustrations/   ← UI-## files
├── animations/         ← AN-## files (Lottie JSON)
├── marketing/          ← MK-## files
├── audio/
│   ├── narration/      ← AU-## narration files
│   ├── characters/     ← AU-## character voice lines
│   ├── sfx/            ← Short sound effects
│   └── music/          ← Background music loops
└── source/             ← Figma, PSD, AI source files (backup only)
```
