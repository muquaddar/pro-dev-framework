# Pro Dev Framework — Changelog

All notable changes to this framework will be documented in this file.

## [1.0.0] — 2026-04-12

### Added
- **8-Stage Lifecycle**: Idea Exploration → Post-Launch Operations
- **Platform-Split Architecture**: Planning on cloud platforms, building in IDE agents
- **Planning Kit**: 13 knowledge-base files + system prompt for ChatGPT/Claude/Gemini
- **Save-As-You-Go**: Cloud AI outputs exact filenames after each stage
- **Planning Package Validation**: IDE agent validates all planning docs before building
- **Switch Protocol**: Agent asks target → saves state → generates platform-specific handover
- **Universal State Protocol**: 4-layer memory (digest, state, snapshots, context packages)
- **3 Project Tiers**: Lite (weekend), Standard (multi-week), Enterprise (team/compliance)
- **7 Human Gates**: Mandatory approval checkpoints scaled by tier
- **Stakeholder Discovery**: Atomic one-at-a-time deep dives with progress tracking
- **Work Streams**: Parallel tracks for Code, Content, Assets, Legal, Marketing
- **3-Tier Codebase Index**: Project map → Module index → Symbol index
- **Consulting-Grade Methodology**: McKinsey (hypothesis), ThoughtWorks (walking skeleton), Deloitte (stakeholder interviews)
- **5 Harness Adapters**: Claude Code, Codex, Antigravity, OpenCode, Generic
- **5 Stack Templates**: Web (React/Next.js), Flutter, Python, Windows Desktop, Unity
- **Activation Prompt Template**: First-time IDE agent activation with package validation
- **Resume Protocol**: Platform-specific resume instructions for all agent types
